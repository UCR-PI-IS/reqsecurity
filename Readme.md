# LLM Security Requirements Generator

This project consists of a model that generates **security requirements** from **functional requirements**.

## Theoretical Foundation

The proposal is based on the work of **Riaz et al. (2014)**.

## Prerequisites

- Python 3.10+ (recommended)
- `pip`

## Setup

1. Create the virtual environment:

```bash
python -m venv .venv
```

2. Activate the virtual environment:

```bash
.venv\Scripts\Activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Configure the Anthropic API key:

- Go to the constants file.
- Place the Anthropic API key in the corresponding variable.

## Local Execution

To start the server:

```bash
python ./src/mcp_server.py
```

## Expose the Server Publicly (Optional)

If you need public access to the server, you can use:

```bash
cloudflared tunnel --url http://localhost:8000 --http2-origin
```

Then, take the link generated by Cloudflared and add `/mcp` at the end.  
Example:

```text
https://<enlace-generado>/mcp
```

With that, the service is accessible from any compatible model.
